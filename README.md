# 💪 FitLog — Workout Planner

FitLog is a responsive workout library and workout planning application built with **Next.js**.  
Users can explore exercises, view workout details, organize their daily workout plans, and save workouts for later.

---

## 🚀 Technologies Used
- **Next.js** — App Router and routing  
- **React** — UI components and state management  
- **TypeScript** — Type safety  
- **Tailwind CSS** — Responsive styling  
- **DaisyUI** — UI components  
- **Context API** — Shared workout state  
- **localStorage** — Persistent workout data  
- **FitLog Workout API** — Workout information  

---

## ✨ Features
1. **Workout Library** — Browse workout information fetched from an API.  
2. **Workout Details** — View exercise descriptions, equipment, difficulty, and instructions.  
3. **Today's Plan** — Add workouts to a personal daily training plan.  
4. **Saved Workouts** — Save exercises to revisit later.  
5. **Responsive Design** — Works on mobile, tablet, and desktop.  
6. **Workout Tracking** — Track completed workouts and view plan summaries.  
7. **Persistent Data** — Saved workouts and plans survive page reloads.  
8. **Notifications** — Toast feedback when adding or removing workouts.  
9. **Sort Dropdown** — Sort workouts by Duration, Calories, or Rating.  
10. **Mark as Done** — Complete workouts with a check button and toast.
